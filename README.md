# Command Upgrade Training Briefing

Domestic Airlines, Flight Operations and Training: the interactive course of the 20 practical briefings (PL 01 to PL 20) for senior first officers in training for command.

Read each briefing, pass its 10-question knowledge check (8/10) to unlock the next one, and finish with a course certificate. Progress is saved in the candidate's browser.

Training document. Not an approved manual: in case of difference, OM A, OM B, OM C, OM D, SOP, MEL, QRH and AFM apply.
